Configurazioni RAW Cross-Modello

Flusso operativo consigliato per importare da un modello e generare un file RAW per un modello diverso.

Obiettivo

Usare EditRemote in Offline come ponte tra modelli:

  1. Importare una configurazione RAW di origine (anche modello legacy).
  2. Adattare automaticamente i dati al modello target scelto in app.
  3. Esportare un file <nome_modello>_config.raw pronto per l'import lato cassa.

Procedura Passo-Passo

  1. Apri EditRemote e seleziona Modalita: Offline.
  2. Nel campo Modello Offline seleziona il modello di destinazione (es. ZERO TOP).
  3. Apri Configurazioni ( Import / Export - 850/851 ).
  4. Premi Import (851) e seleziona il file RAW di origine.
  5. EditRemote legge modello/revisione sorgente e adatta i campi al modello target.
  6. Verifica le sezioni principali (Reparti, Pagamenti, Opzioni, ecc.).
  7. Premi Export (850) per generare <nome_modello>_config.raw.
  8. Copia il file su USB e usa il comando di import (857) sulla cassa target.

Regole di Compatibilita

  • Import Sono accettati anche modelli legacy (supporto in sola importazione).
  • Export Disponibile solo per modelli correnti.
  • Tastiera Se la Dimensione tastiera sorgente e target differisce, la tastiera non viene trasferita.
  • Tastiera Se la Dimensione tastiera e uguale, la tastiera viene mantenuta.
  • Nota TIPO_TASTIERA corrisponde alla Dimensione tastiera.

Note Pratiche

  • Nei passaggi tra modelli con meno reparti/pagamenti, i record eccedenti vengono esclusi.
  • Dopo l'import, e consigliato rivedere sempre Reparti, Pagamenti, Opzioni e POS.
  • Il file export standard e <nome_modello>_config.raw.
