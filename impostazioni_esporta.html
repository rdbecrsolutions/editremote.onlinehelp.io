Guida operativa

Questa sezione richiede alla cassa i file di export storico e li salva nella cartella export dell'app.

Nota operativa: per File di Log non e' richiesto l'intervallo date; per gli altri tipi export imposta Data inizio e Data fine.
Come usare la pagina
  1. Apri Esporta dalla lista Configurazioni.
  2. Seleziona il Tipo export.
  3. Se richiesto, imposta Data inizio e Data fine.
  4. Premi Invia richiesta per avviare l'export dalla cassa.
  5. Premi Apri cartella export per consultare i file ricevuti.
Significato campi e pulsanti
  • Tipo export: seleziona il dataset richiesto (XML chiusure, documenti con CF, tutti i documenti, documenti chiusure, XML lotteria, file di log).
  • Data inizio / Data fine: intervallo dell'estrazione per i tipi export che lavorano per data.
  • Invia richiesta: invia la richiesta alla cassa via protocollo export.
  • Apri cartella export: apre la cartella locale dove vengono salvati i file.
  • Esci: chiude la finestra senza nuove richieste.
Se la comunicazione e' occupata da altre operazioni, attendi la fine prima di lanciare un nuovo export.
Controlli finali consigliati
  • Verifica che i file risultino nella cartella export della matricola corrente.
  • Controlla il nome file e il range date richiesto.
  • In caso di timeout, riprova restringendo l'intervallo date.
