Programmazione guidata
Prima di programmare, togli dalla cassa eventuali chiavette USB con il file Tecnico.dat esteso. Se restano inserite, la programmazione viene subito sovrascritta dai dati della chiavetta.
  1. Togliere la chiavetta USB dalla cassa
    Se la chiavetta con Tecnico.dat esteso resta inserita, i dati che hai appena programmato vengono cancellati.
  2. Compilare i campi
    Inserisci i dati richiesti nella schermata: mail, password tecnica, partita IVA, regione e lock cfg.
    La partita IVA è quella dell'attività in cui è installata la cassa. La regione è quella in cui si trova l'attività. La password tecnica è la password che protegge le impostazioni tecniche della cassa.
    I campi mail sono gli indirizzi di posta indicati nella schermata. Verifica che siano corretti prima di salvare.
  3. Confermare con il codice di conferma (OTP), se richiesto
    Se modifichi una delle mail, la partita IVA o la password tecnica, il sistema chiede un codice di conferma (la sigla OTP indica un codice usa e getta). Premi Invia OTP, attendi il codice ricevuto e inseriscilo nel campo OTP.
    Il codice arriva all'indirizzo indicato nel campo Email OTP (mail_otp): è l'indirizzo e-mail che riceve il codice di conferma.
  4. Scegliere i blocchi da proteggere
    Spunta le impostazioni che vuoi bloccare nella sezione lock configurazioni.
  5. Salvare
    Premi Salva per inviare la programmazione alla cassa.
  6. Creare il file Tecnico.dat aggiornato
    Dopo aver salvato correttamente, premi Genera Tecnico.dat. Il file viene inviato via mail all'indirizzo del campo Email OTP (mail_otp).
    Il servizio di posta blocca gli allegati con estensione .dat: il file arriva come .txt. Prima di usarlo, rinominalo manualmente in Tecnico.dat.
Schermata di riferimento: Programmazione Park Protection.
